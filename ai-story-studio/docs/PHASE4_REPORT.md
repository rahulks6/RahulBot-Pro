# Phase 4 report: real episode assembly, AI audio adapters, upscaling, lip sync and voice consent

**Status: Phase 4 is implemented and verified. Waiting for your approval before Phase 5 (one cloud GPU provider).** Nothing was rented, called or downloaded. The cost was ₹0 and `MOCK_GENERATION=true` is still the default.

Two real bugs were found and fixed by the FFmpeg tests:

- `xfade` fails after `concat` (timebase mismatch); all inputs are now normalised with `settb=AVTB`.
- `drawtext` treated `%` in titles as an expansion sequence; `expansion=none` is now set.

## Honest limits

- **No real AI model ran here.** There is no GPU and no model or PyPI downloads in this environment. The Stable Audio, spandrel and Chatterbox-reference adapters are tested against fakes that follow the documented APIs. The subprocess, FFmpeg and audio post-processing parts are real. Your first GPU benchmark is the real verification; failures show up as clear job errors.
- **LatentSync's command line** in `models.example.json` follows its README as of September 2026. Check it against the version you install.
- **ACE-Step and MuseTalk** have no dedicated adapter yet. MuseTalk can run through `command_lipsync` with a wrapper script.
- **Visual quality of the MP4 depends on the clips.** In mock mode, the footage is placeholder stills. The encode, transitions, loudness and validation are real.
- Revoking consent cannot recall videos that were already exported or published. The app says so when you revoke.

## What you need to do

1. Install FFmpeg on the app machine (or set `FFMPEG_PATH` / `FFPROBE_PATH`). Then run `npm run seed` and open the export to see a real MP4.
2. On the GPU machine, run `pip install -r worker/requirements-gpu.txt`. Enable and benchmark Stable Audio Open (acknowledge its licence first) and Real-ESRGAN (with a weights file you downloaded), and configure LatentSync if you want lip sync. Follow [BENCHMARKING.md](BENCHMARKING.md).
3. For voice cloning, record a consent entry for every real speaker before attaching a reference.
